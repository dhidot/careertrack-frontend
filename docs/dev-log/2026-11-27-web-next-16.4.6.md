# Upgrade Next.js 16.4.0 → 16.4.6 untuk apps/web

**Tanggal:** 27 November 2026
**Branch:** `chore/web-next-16.4.6`
**Status:** Selesai, siap merge. GitHub Actions sedang dimatikan, jadi semua verifikasi di bawah dijalankan lokal sebagai pengganti CI.

## Kenapa

Saat `next build`, Next.js 16.4.0 menghentikan proses dengan `SecurityFatalError`: versi ini terkena kerentanan keamanan yang sudah dipublikasikan. `apps/cms` sudah di-upgrade di PR #11, tapi `apps/web` (app yang dipakai user dan di-deploy ke Vercel) masih 16.4.0. 16.4.6 adalah rilis patch di jalur 16.4 yang sama, jadi tidak ada perubahan API yang diharapkan.

## Yang berubah

| File | Perubahan |
|---|---|
| `apps/web/package.json` | `next` dan `eslint-config-next`: `16.4.0` → `16.4.6` (versi exact, sama seperti sebelumnya) |
| `pnpm-lock.yaml` | Paket Next 16.4.0 hilang karena web dan cms sekarang memakai versi yang sama. Lockfile berkurang sekitar 190 baris. |

Dibuat dengan `pnpm --filter web add --save-exact ...` dari branch baru berbasis `main`, bukan dari branch logout yang sudah di-merge.

**Catatan:** PR #11 menambahkan `experimental.agentUpgrade: "security"` di `apps/cms/next.config.ts`. Setting itu tidak ditambahkan ke web di PR ini karena hanya memengaruhi pengingat upgrade, bukan perilaku aplikasi. Kalau mau konsisten, bisa ditambahkan terpisah.

## Temuan sampingan: redirect `/dashboard` untuk user anonim

`GET /dashboard` tanpa login membalas **200**, bukan 307. Ini bukan bug dan bukan akibat upgrade:

- `ServerSessionGuard` berada di dalam `<Suspense>` (`app/(app)/layout.tsx`). Next.js sudah mulai streaming HTML sebelum guard selesai memeriksa sesi, jadi status 200 sudah terkirim.
- `redirect()` lalu dikirim di dalam stream sebagai penanda `NEXT_REDIRECT` dan `<meta http-equiv="refresh">` ke `/session/recover?next=%2Fdashboard`.
- Isi halaman private tidak ikut terkirim karena `redirect()` menghentikan render children.

Kalau suatu saat ingin 307 yang "asli" (misalnya demi SEO atau monitoring), pengecekan sesi bisa dipindahkan ke `proxy.ts`/middleware atau ke luar `<Suspense>`.
